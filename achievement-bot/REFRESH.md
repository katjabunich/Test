# Инструкция для повторяющейся сессии

Это текст, который вешается на расписание в Claude Code (раз в 1–2 недели).
Он не требует платного API: всё делает сама сессия по подписке, а бот потом
только достаёт готовое из базы.

## Что вставить в расписание

```
Обнови дневник достижений в Supabase (проект guypbszfncsskkqmfzfp, схема achievements).
Следуй правилам тона из achievement-bot/TONE.md репозитория katjabunich/Test,
ветка claude/achievement-tracking-app-t1yw1. Сделай ровно четыре шага:

1. ПОЧИСТИТЬ НАДИКТОВАННОЕ
   Возьми записи за последние 14 дней (achievements.entries).
   Часть надиктована через Wispr Flow и содержит явные ошибки распознавания
   («полдьзоваььсч», «горажданкой», «немиоооя»). Исправь ТОЛЬКО очевидные
   ошибки распознавания. НЕ переписывай формулировки, не улучшай стиль,
   не удаляй ничего. Сомневаешься — оставь как есть.

2. ПРОВЕРИТЬ ТЕМЫ
   Записи размечаются автоматически при сохранении. Посмотри, что попало
   в тему «Разное» за последние 14 дней. Если видно очевидную тему —
   проставь её. Если появилась новая устойчивая тема, скажи об этом в отчёте,
   но правила в коде сам не меняй.

3. НОВЫЕ НАБЛЮДЕНИЯ (главное)
   Сначала прочитай ВСЕ существующие achievements.insights, чтобы не повторяться.
   Потом прочитай записи, добавленные с момента прошлого запуска.
   Напиши 8–12 новых наблюдений о закономерностях, которые в них видны.
   Каждое — с её же цитатами. Вставь в achievements.insights
   (user_id = владелец, kind = 'pattern', last_sent_on оставь NULL).
   Бот отправляет каждое ровно один раз, поэтому запас важнее красоты.

4. ПИСЬМО (только если сегодня первые числа месяца)
   Если в achievements.letters нет письма за прошлый месяц — напиши его
   по записям того месяца и вставь (period в формате '2026-08', sent_on NULL).
   Бот отправит его сам 1-го числа в 12:00.

В конце коротко отчитайся: сколько записей почищено, сколько наблюдений
добавлено, написано ли письмо.
```

## Проверка тона перед вставкой

Каждое наблюдение проходит два вопроса из TONE.md:
1. Есть ли намёк, что ей надо стать другой? → переписать.
2. Опирается ли вывод на записи, или достроен? → сузить до записей.

И отдельно: никаких выводов масштабом в год или в жизнь.

## Как понять, что запас кончается

```sql
select count(*) filter (where last_sent_on is null) as осталось
from achievements.insights;
```
Меньше 5 — пора запускать.
