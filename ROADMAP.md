# Дела — план развития

Текущая версия (v1, ветка `claude/task-tracker-app-LqhzE`) — функциональный личный
task-tracker с экранами Сегодня / Все / Привычки / Опции, привязанный к Supabase,
v4 hi-fi дизайн (тёплая бумага + Tiffany-мятный акцент, шрифт Onest + JetBrains Mono).

Ниже — план следующих фаз. Каждая самостоятельная, можно ставить и тестировать
отдельно.

---

## Фаза A — Цели и стратегия

**Боль**: «несостыковка реальной жизни и того, что я делаю каждый день».

- Таблица `goals` (id, user_id, sphere_id, title, description, target_date, status, created_at)
- Поле `goal_id` (опциональное) у задачи
- Экран `/goals` — карточки целей с прогресс-баром (% выполненных задач)
- Внутри цели — её задачи (активные + история)
- В модалке задачи — выбор цели (если у её сферы есть цели)
- На главной — мини-блок «движение к цели» (% за неделю)

**Открытые вопросы перед стартом**: цель внутри одной сферы или вне их?
дедлайн обязательный? прогресс — % выполненных или ползунок руками?

---

## Фаза B — Уведомления

**Боль**: «забываю про дела, день уходит в пустоту».

- Web Push API через service worker (SW уже зарегистрирован)
- Таблица `push_subscriptions` (как в plant-app)
- Supabase Edge Function (cron, раз в день в 8:00) — утренняя сводка
- Отдельный hook на просрочку (раз в день в обед)
- Настройки: toggle «утренние уведомления», время, дни недели

---

## Фаза C — Авторизация и multi-device

**Зачем**: данные перестают зависеть от хардкоженого `DEV_USER_ID`,
можно зайти с компа, защита данных.

- Экран `/auth/sign-in` с одним полем (email)
- Supabase magic link через `signInWithOtp`
- Middleware `proxy.ts` защищает все роуты кроме `/auth/*`
- Миграция: переносим текущие данные с `DEV_USER_ID` на реальный `auth.users.id`
- RLS-политики на все таблицы

---

## Фаза D — Статистика и обратная связь

**Боль**: feedback loop, «куда уходит неделя».

- Карточка «итоги недели» на главной воскресным вечером
- Экран `/stats`:
  - Бар-чарт «задач выполнено по сферам за неделю»
  - Heatmap «активность по дням» (а-ля GitHub)
  - Среднее задач/день
  - Если есть цели — % движения к ним

---

## Фаза E — Архив и поиск

- Экран `/archive` — выполненные задачи (`completed_at != null`)
- Поле поиска в `/tasks` — full-text search в Postgres
- Фильтры по диапазону дат
