# DoIt — правила проекта

Персональный task/habit-трекер Кати (katjabunich). Next.js App Router +
Supabase, PWA, пользуется только с телефона (iPhone, standalone PWA).
Деплой: пуш в ветку `claude/task-tracker-app-LqhzE` → Vercel
авто-деплоит doit-tracker.vercel.app (~2 мин).

## Правило №1: приложение всегда ДО КРАЁВ экрана (требование Кати)

Приложение обязано занимать весь физический экран телефона, включая
зону статус-бара («под часами») и нижний home-indicator. Никаких
кремовых/белых полос сверху или снизу. Это уже настроено — НЕ ломать
при правках:

- `layout.tsx`: `appleWebApp.statusBarStyle: "black-translucent"`
  (webview на весь экран; `default` возвращает полосу — не менять) +
  `viewport.viewportFit: "cover"`.
- `globals.css`: `main { padding-top: env(safe-area-inset-top) }` и
  `padding-bottom: calc(112px + env(safe-area-inset-bottom))` — контент
  не залезает под часы и home-indicator.
- `layout.tsx`: фиксированная тёмная вуаль-градиент высотой
  `env(safe-area-inset-top)` (z 60) — белые системные часы читаемы на
  светлом фоне. Не удалять.
- Декоративные фоны (небо/солнце на Today) обязаны дотягиваться до
  физического верха: расширение вверх на `env(safe-area-inset-top)`.
- Любой новый полноэкранный фон/градиент — от кромки до кромки, без
  «швов» в крем (растворять градиентом, как небо на Today).

## Ловушка, из-за которой «пропадало солнце»

Элемент с `z-index: -1` внутри контейнера БЕЗ собственного
stacking-context рисуется ПОЗАДИ фона body — т.е. невидим. Контейнеру
декора нужен `isolation: "isolate"` (уже стоит на Today). Помнить при
любом новом фоновом декоре.

## Дизайн-система «Рассвет» (утверждена Катей)

- Тёплый крем `--paper #FBF7F1`, чернила `#3B2E26`, главный акцент
  терракота `--terra #C4673F`, вторичный карамель `--caramel #D9A05B`.
  Токены в `src/app/globals.css` — менять значения только по её просьбе.
- Шрифты: M PLUS Rounded 1c (display, крупные пухлые заголовки) +
  Nunito (body). Serif запрещён. Эмодзи как иконки — нежелательны.
- Цвета сфер/привычек из БД прогоняются через `src/lib/palette.ts`
  (warmBase/warmTint/warmStrong) — НЕ использовать сырые hex из БД в UI.
- Тёмные темы Катя не приемлет. Конфетные пастели и «детскость» — тоже.
- Солнце на Today: целый мягкий диск + свечение справа сверху,
  НЕ обрезать краем, не превращать в маленький «шарик» (вариант «c»;
  `?sun=a|b` — запасные варианты для сравнения).
- Просрочка: без красного; на Today живёт в свёрнутой секции «Ждут
  своего часа» внизу с кнопками «На сегодня» и массовыми действиями.

## Рабочий процесс

- Стили — инлайн в JSX + токены/классы в globals.css; Tailwind не
  используется. Примитивы — `src/components/ui.tsx`.
- Все строки UI — через `src/lib/i18n/dict.ts` (ru + en).
- Перед пушем: `npm run build` обязан проходить.
- Визуальные правки проверять скриншотом: `/preview` — мок-версия
  Today без Supabase (Playwright, viewport 390×844).
- Катя смотрит результат только на doit-tracker.vercel.app с телефона;
  большие визуальные изменения сначала показывать ей скриншотом или
  макетом, потом пушить.
- Не сломать: свайпы задач (влево — сделано, вправо — отложить),
  dnd-kit сортировку, звуки/вибро (`lib/feedback.ts`), конфетти,
  оптимистичный UI, reduced-motion.
